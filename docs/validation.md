# Windows 2.1.4 / Android 1.0.5 发布验收

2026-10-23，用户在检查独立 MP3 提取页和滚轮交互修正后授权发布，并要求 Android 同步升级。本次为 Windows 2.1.4 与 Android 1.0.5（versionCode 105）。

## 源码与界面

- 120 项单元检查、32 项内核冒烟检查通过，覆盖格式转换、完整解码、各 MP3 码率、无音轨、受损缓存、无 JSON 图文、删除、迁移及两页任务隔离。
- 27 项真实 Qt / FFmpeg MP3 流程检查通过：本地 MP4 实际提取、原视频哈希未变、无 JSON 附件、入库、独立页面与状态保留。
- 26 项原界面流程检查、100% 与 150% 各 47 项界面检查通过，已查看默认、紧凑、宽窗口、展开侧栏、设置及完成状态截图。
- 5 个设置下拉框分别实测有焦点和无焦点，共 10 组：滚轮不改值、不保存新设置，页面继续滚动；点击和键盘选择、保存正常。视频库排序共用相同控件。
- 发布源码只包含应用源文件、许可证、复现脚本与公开文档；构建、用户媒体、设置、浏览器资料和本地诊断图片不进入源码包。

## Windows 成品验收

- 实际冻结 EXE 在仅保留系统 PATH 的隔离环境中通过 47 项检查：独立 MP3 页面、首页恢复、控件滚轮行为、真实内置工作进程提取、192 kbps MP3 全解码、原 MP4 不变、无 JSON 附件、入库、进度保留、视频解码与播放器导出入口。
- 使用独立 AppId 的真实安装器完成首次安装、保存位置选择、迁移、视频删除、单图删除和覆盖重装；10 项外层安装检查及 11 项冻结应用检查通过，目录、媒体字节、历史记录和设置保留。
- 独立冻结更新助手将隔离的 2.1.3 副本升级到 2.1.4，19.09 秒完成并验证 nonce、实际启动版本和首页；原视频 SHA-256、设置、登录资料与历史记录保留。
- 所有安装和迁移检查使用隔离目录，没有对用户真实媒体执行删除或迁移。

## Android 成品验收

- 实际签名 APK 为 1.0.5（versionCode 105），包含 ARM64 与 x86_64 两套运行库，签名证书与旧版 1.0.4 一致，可覆盖升级。
- x86_64 Android 模拟器实际经过系统文件选择器导入含中文和加号的 MP4，经前台服务、内置 Python 与 FFmpeg，保存到 MediaStore。生成 MP3 的 MIME 为 `audio/mpeg`，145772 字节、6.048 秒、192 kbps，完整解码通过；原视频 SHA-256 未变，没有新增公共 JSON。
- Android 实际运行时的 11 项格式及 MP3 码率组合转换通过。
- 将 MP3 设为 320 kbps 后实际强制停止应用并重启，设置仍保留。
- 使用 20 分钟测试视频在转换中取消，界面恢复就绪，没有发布新的媒体文件，原视频保持不变；系统文件选择器取消也恢复就绪。
- 已查看独立下载、提取 MP3、设置三页的界面预览及设备提取完成截图，使用统一蓝灰风格。以上设备验证范围为 x86_64 模拟器；ARM64 已构建并签名，未进行 ARM 实机测试。

## 边界

公开 Bilibili 链接使用无浏览器登录的 MP3 在线测试时返回 HTTP 412，未进入媒体下载，不视为在线验收通过。链接音轨选择和转换用受控解析器与真实 FFmpeg 验证，本地视频提取已实测；抖音与 X 的真实在线 MP3 尚未实测。

MP3 与图文配乐使用系统默认播放器。Windows 10 实机、双屏热切换和长期大规模媒体库压力测试尚未覆盖。既有存储、删除及视频播放器记录见 `bilibili/STORAGE_REVIEW.md`，本轮功能检查细节见 `bilibili/EXPORT_REVIEW.md`。
