# Android 1.0.7 更新下载交接

用户要求：点击下载更新后交给手机浏览器，安装包与进度能在浏览器下载列表或系统通知中找到；退出视频下载器后仍可查看。

1.0.6使用Qt的通用打开链接入口。Qt实现为普通ACTION_VIEW，未明确限定完整浏览器，也未要求独立任务；不能仅凭用户看到的窗口判定它是应用内WebView。

本次改为原生浏览器交接：

- 优先手机默认的完整浏览器；只有一个可用浏览器时直接打开，多个且无默认时仅显示浏览器选择。
- 使用普通可浏览网页Intent、明确浏览器组件和独立任务，让浏览器接管APK下载。
- 排除自身和已知WebView演示壳。没有可用浏览器、链接无效或启动失败时显示明确提示，可重试。
- 只传递本项目官方APK链接，不传递站点登录Cookie。浏览器决定下载确认、保存目录和通知方式；通常可从其下载列表及手机Download目录查找。

验证使用隔离Android模拟器与Mozilla官方Firefox。测试包仅在本地注入一条更新可用事件来点击真实QML按钮，下载对象为已公开的1.0.6 APK；线上版本清单未修改，产品APK不包含测试入口。

验证结果（2026-11-13）：

- 正式签名的1.0.7（versionCode 107）双ABI构建通过，签名证书与1.0.6一致，可覆盖安装。
- 从真实设置页点击“下载更新”，打开独立Firefox任务；没有可用浏览器时显示可重试提示，不打开WebView演示壳。
- 下载期间强制关闭视频下载器，Firefox仍继续下载；浏览器下载列表显示127 MB / 158 MB，系统通知也保留进度。
- 下载完成后文件位于`/storage/emulated/0/Download/VideoDownloader-Android.apk`，158247185字节，SHA-256与线上1.0.6完全一致。
- 本次仅在隔离模拟器验证Firefox，未声称已验证用户实体手机上的所有浏览器。保存目录与下载确认由所选浏览器决定。
