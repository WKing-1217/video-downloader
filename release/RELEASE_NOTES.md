# 视频下载器 Android v1.0.6

- 优化蓝灰界面，修复状态栏与标题重叠、底部导航宽度和图标对应；键盘、横屏与系统播放器返回后保持正常布局。
- 新增作品库，支持搜索、查看、分享、整组删除和图文单文件删除，删除前确认。
- 支持选择保存文件夹并迁移已有作品，逐项校验后清理登记的旧文件，同名文件另存，保留其他文件。
- 下载与提取 MP3 可连续添加任务排队，分别保留输入和状态；支持本地视频提取音轨。
- 补齐 Instagram 单视频、YouTube / Shorts 链接下载，内置所需运行环境。
- 修复抖音实况图文下载：静态照片、实况视频和配乐分别保存，传输中断有限重试，完成后校验文件和完整解码。

Android 10+，包含 ARM64 / x86_64。与旧版签名一致，可直接覆盖安装，无需卸载。

已在 Android 30 x86_64 模拟器实际完成 Instagram、YouTube 和抖音实况下载；实况导出3张照片、1段动态视频和1首配乐。另已检查目录迁移、删除、冷启动恢复及播放器返回。ARM64实体手机及厂商刘海/手势布局未覆盖。

本次更新 Android；附带的 Windows 安装包继续提供 v2.1.5。两端版本分别记录，保留历史版本供恢复。Instagram图片/轮播、YouTube频道/播放列表及直播不在本次新增范围。
