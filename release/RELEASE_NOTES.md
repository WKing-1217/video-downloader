# 视频下载器 Windows v2.1.1

- 首次安装可选择视频和图片的保存位置，设置与视频库内也可更改。
- 更改位置后自动迁移原作品，逐个校验后更新视频库并清理旧文件与空目录；支持取消和中断恢复，不覆盖同名文件，不删除其他个人文件。
- 支持在软件内删除视频、整个图文作品或单张图片，删除前确认，完成后同步作品列表；播放器内也可直接删除。
- 展开侧栏可拖动调整宽度并自动适配窗口；长标题边缘渐隐，从右向左单向循环滚动，不再左右往返。
- 播放器和图文查看器改为独立窗口，可最小化、最大化，也能正常切回视频库。
- 修复保存目录配置的读取与保存，隔离预览、测试和正式版配置，升级保留已选目录与原有记录。

保留原有下载队列、历史视频库、内置播放、账号登录及安全更新能力。安装到原目录即可升级，设置、登录资料和已保存作品继续保留。

Windows 支持 Windows 10 / 11 x64，安装包内置运行环境和 FFmpeg。

本次仅升级 Windows；附带的 Android 安装包保持 v1.0.4。
