# 视频下载器 Android v1.0.7

- 修复“下载更新”的浏览器交接，优先使用手机默认浏览器；没有默认浏览器时可选择可用浏览器。
- 浏览器独立处理安装包下载，退出视频下载器后仍可从浏览器下载列表查看进度、找到安装包。
- 未安装或未启用可用浏览器时显示提示，可重新尝试。

Android 10+，包含 ARM64 / x86_64，与旧版签名一致，可直接覆盖安装，无需卸载。先安装本版，之后更新按钮才会使用新的浏览器交接方式。浏览器可能要求确认下载，保存位置和通知由所选浏览器管理。

已在 Android 30 模拟器用 Firefox 实测：从真实更新按钮打开独立浏览器任务，强制关闭视频下载器后下载继续，完整安装包校验通过。尚未验证所有厂商实体手机浏览器。

本次只更新 Android；Windows 安装包继续提供 v2.1.5。保留此前正式版本供恢复。
