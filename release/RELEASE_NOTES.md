# 视频下载器 Windows 2.1.6 和 Android 1.0.9

- 修复部分抖音作品选中附带片尾的下载源，因时长不符而无法导出。优先使用有完整画面和声音的播放源，继续校验成品时长及解码完整性。
- 识别带 `https\://` 的抖音分享文字。Android 的粘贴、系统分享和队列去重均支持这种写法。
- Windows 修复关闭浏览器自动扫描后未使用程序内网页登录的问题，并为 Instagram 访问限制提供中文提示。更新下载遇到限流或地址过期时，可继续已完成的部分并有限重试。

可在软件内检查更新，也可下载安装包覆盖安装。Android 支持 Android 10 及以上，包含 ARM64 和 x86_64，签名与 1.0.8 一致。

Windows 成品和 Android x86_64 模拟器均通过抖音原片下载、MP3 导出和覆盖升级检查。两端实际导出的 MP4 均为 8.06 秒，含画面和音轨。Instagram 受限视频的会话逻辑通过自动测试，登录后的在线下载未验证。Android 本轮未覆盖实体 ARM64 手机。
