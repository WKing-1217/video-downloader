# 视频下载器 Android v1.0.8

- 更新安装包改为在软件内下载，显示真实下载量与进度，支持取消、重试及重新打开软件后恢复任务。
- 下载完成先校验安装包大小、SHA-256、包名、版本、签名和原生解析结果，再自动打开系统安装界面。
- 首次安装来源授权后继续安装，修复系统授权时重建进程导致安装中断的问题；取消安装后可再次打开安装界面。

Android 10+，包含 ARM64 / x86_64，与旧版签名一致，可直接覆盖安装，无需卸载。先安装本版，之后软件内更新才会使用新流程。首次需要允许本软件安装应用，最终安装仍由您在系统界面确认。系统下载通知保留；后台完成下载时，回到软件后继续处理安装。

已在 Android 30 模拟器完成真实 GitHub 下载进度、任务恢复和取消检查；安装包校验及系统安装交接使用未发布、未实际安装的受控测试包验证，授权时系统重建进程后仍能自动进入安装确认。未在小米实体手机复测，不能确认截图中解析错误33的具体原因。

本次只更新 Android；Windows 安装包继续提供 v2.1.5。历史正式版本保留。
