# 视频下载器 Windows v2.1.4

- 新增独立“提取 MP3”页面：支持作品链接和本地视频；视频库与播放窗口也可直接导出 MP3，原视频保留。
- 首页保持原有简洁布局，提取页沿用统一蓝灰主题；两页分别保留输入、错误、进度和重试状态。
- 视频默认 MP4、图片默认 PNG；设置中可选 MKV、MOV、WebM、JPEG、WebP，MP3 支持 128、192、256、320 kbps。
- 新导出只保存媒体文件，不再生成视频或图文信息 JSON 附件；作品信息继续保存在内部媒体库，兼容已有作品。
- 下拉框取消滚轮切换，滚轮只用于滚动页面，避免误改格式、音质、登录来源和排序。
- 完善同名另存、完整性校验、图文整组保存、损坏缓存重试及两页任务隔离。MP3 使用系统默认播放器打开。

安装到原目录即可升级，保存位置、视频、历史记录与登录资料继续保留。

Android 同步升级至 v1.0.5，新增独立 MP3 提取页、导出格式设置与本地视频提取，统一蓝灰风格。
