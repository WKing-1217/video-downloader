# 视频下载器 Windows v2.1.0

- 全新黑白简约界面：首页保留问候、链接输入框和最近三个作品预览。
- 粘贴只填入链接；点击右侧黑色箭头或按 Enter 开始下载，避免误触。
- 新增可展开、收起的完整侧栏，支持直接打开最近作品；收起时保留下载、视频库和更新三个图标。
- 搜索使用独立窗口，支持方向键选择、Enter 打开和 Escape 关闭；关闭后保留原页面与视频库筛选。
- 放大设置与账号窗口，支持手动调整大小。
- 重新设计黑白品牌 Logo，同步软件、窗口和任务栏图标，优化不同缩放下的布局与焦点状态。

保留原有下载队列、历史视频库、内置播放、账号登录及安全更新能力。安装到原目录即可升级，设置、登录资料和已保存作品继续保留。

Windows 支持 Windows 10 / 11 x64，安装包内置运行环境和 FFmpeg。

本次仅升级 Windows；附带的 Android 安装包保持 v1.0.4。
