# 界面与交互

这是一个已可用的 Qt 桌面下载工具，供用户把 Bilibili、抖音、X 分享链接保存为本地完整视频。核心对象是链接、登录来源、下载任务和文件。入口是复制链接后打开程序；第一步是粘贴链接，平台在后台自动识别，主操作是开始下载。信息顺序为链接、下载按钮、登录状态、任务进度、输出目录，技术日志默认折叠。成功后显示完整时长、画质和音频，并可打开视频或目录。失败保留链接、说明原因并允许重试。需要账号权限时自动扫描当前用户的浏览器登录信息；加密保护或文件占用必须如实显示，可用程序内网页登录恢复。另有独立的 Qt Quick 安卓客户端。

采用 PySide6 / Qt Widgets，参考 Qt 原生桌面交互和 Fluent 的清晰层级。风格简洁、浅底、柔和粉色强调、大字号。统一维护颜色、字体、间距、组件尺寸。界面使用“链接、下载、画质、音质、文件夹”等用户词汇，不展示编码器参数作为主内容。不堆砌卡片、装饰性指标、技术术语或无关设置。基线风险是长标题截断、下载线程阻塞、只下载预览和失败后误报成功；使用子进程、自动换行、流及完整时长校验处理。验证包括真实下载、媒体探测、解码检查和 Qt 离屏截图。

保留原有大字与布局，提供扫描和网页登录操作，浏览器来源放在折叠区。窗口内容可滚动，避免展开日志后超出桌面。登录值不进入可见状态或日志；只在具体平台范围内使用，账号不混合。验证覆盖三平台识别、域名欺骗、过期 Cookie、加密保护、账号来源选择、Qt 实际子进程与网页登录窗口；外部网站验证和网络失败必须与下载成功区分。

1.0.1 按用户标注精简桌面文案：窗口名仅“视频下载器”，删除平台及说明两行，输入区仅“视频链接”和“链接粘贴处”，隐藏识别提示行。后台识别、账号和质量选择保持自动运行。HTTP 使用有界 8 连接，逐段验证范围与长度；异常时使用 B 站提供的同格式备用节点，检查断点前缀，必要时回退兼容下载。旧成品校验失败时先保留到“未通过校验”再重新下载，不能因文件已存在而反复复用损坏音轨。

后端自动继承 Windows 已启用的系统代理，避免把 Node 代理开关误当作实际代理地址。抖音公开数据必须与请求视频 ID 精确匹配，音频质量按真实音轨检查；画质和音质分别选取，使用 FFmpeg 复制合并。文件名区分格式组合，避免已有文件阻止质量升级。界面主流程继续只展示平台、进度、结果，不向用户暴露这些处理细节。

抖音图文及实况作品沿用同一个链接输入框和下载按钮。按实际内容显示图片数量、实况片段和配乐数量，完成操作为“查看作品文件夹”；原图片、实况 MP4、配乐分别保留，不合成伪原片。普通视频保留播放按钮和完整音画时长校验。图文逐项校验尺寸、实况及音乐时长并完整解码，缺失任一已声明素材时不能显示完成。图文及配乐避开自动系统代理的海外出口，显式代理设置继续优先。

1.0.2 的更新入口放在原选项行右侧，不增加主流程说明行。后台检查仅改变更新入口文字，网络失败不弹窗；手动检查才打开对话框。Windows 更新包校验后由用户安装，安装前必须结束视频任务。两端均可关闭启动检查。设置合并保存，更新开关和视频目录不能互相覆盖。发布文件名固定，各平台仅保留最新版。

1.0.3 的登录来源收起时忽略滚轮，将页面滚动交还外层；展开后保留列表滚动、点击和键盘选择。下拉箭头使用统一颜色的 SVG，避免原生箭头边框与圆角输入框冲突。
