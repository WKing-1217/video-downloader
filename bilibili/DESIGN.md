# Windows 蓝灰 UI 约定

本轮为 Windows 2.1.1 原生 Qt / PySide6 桌面端，大人已检查并授权发布目录迁移、侧栏适配和删除功能，最后确认长标题从右向左单向循环。遵守根目录 AGENTS.md 中大人明确确认的 UI 偏好。Android 保持 1.0.4。

## 首页与导航

默认 1120×780，最小 860×620。背景为浅蓝灰，侧栏使用更深一层的淡蓝灰，内容区为白色；主按钮、选中导航和进度使用深蓝灰，成功状态使用低饱和青灰，文字为深蓝黑，媒体内容保留原色。颜色、字号、间距和组件尺寸统一定义在 ui_theme.py。

首页内容居中，最大宽度 780px：一句问候、一个链接输入框、右侧独立粘贴图标和深蓝灰箭头按钮，下方并排展示最近三个真实作品缩略图。标题只作为作品内容显示，时长位于封面角落；不增加平台徽章、日期、体积、快捷键教程、目录栏、口号或说明副标题。没有任务时隐藏整个任务区域，没有作品时不生成虚假缩略图。

左侧默认 72px 窄图标栏，以细竖线分隔内容区。顶部为原创折帧线条 Logo，下方按下载、提取 MP3、视频库和更新排列，移除收起状态的独立搜索图标，底部为灰阶账号 / 设置入口。默认不展示文字标签，通过悬停提示与无障碍名称识别。点击 Logo 后，整个全高侧栏展开到 280px，显示导航名称、真实最近作品以及底部设置入口；顶部提供搜索和收起按钮。展开是主窗口布局的一部分，不弹小菜单。两个状态共享当前页面和导航选中状态。

2026-10-23：大人要求 MP3 提取独立成页。首页保持原问候、链接框和三个作品缩略图，不放类型下拉或本地提取按钮。提取页使用相同的内容宽度、输入框、独立粘贴按钮和深蓝灰提交按钮，居中显示“提取 MP3”，输入框下保留“选择本地视频”入口，不增加说明卡片、口号或装饰。两页共用输入与任务组件，各自保留输入、错误、进度与重试对象；视频库和播放器的导出入口统一进入提取页。清空提取队列不影响视频下载队列。

搜索入口打开独立的 640×480 窗口浮层，过滤真实作品标题并直接打开作品，支持方向键选择、Enter 打开、Escape 关闭。搜索不切换底层页面，不修改视频库筛选条件，也不占据一个页面选中状态。Ctrl+K 打开搜索，Ctrl+B 切换侧栏。

## 输入与真实状态

粘贴按钮、Ctrl+V 和右键粘贴仅填入内容。点击深蓝灰箭头或按 Enter 后验证并排队，同一规范化链接去重。不监听全局剪贴板，不在输入未完成时下载。

有实际任务时才在输入框下方显示标题、状态、进度与必要操作。解析、下载和合并在独立后台进程执行；实际字节、速度和剩余时间来自原服务，未知总量不生成假百分比。失败、取消、完成以文字和图形区分，使用低饱和状态色与文字。失败或取消后不显示继续下载的速度与 ETA，保留重试与登录入口。

## 作品与弹窗

首页三个预览共用视频库后台缩略图生成与缓存，鼠标单击和键盘回车均可打开作品。库使用原有 QListView 模型和绘制委托，默认三列、最小窗口两列，更宽窗口适应可用宽度。空库与搜索无结果使用简短状态和恢复按钮。

展开侧栏默认 280px，可拖动分隔线在 216–420px 调整，窗口缩小时优先保留主内容至少 560px，并记住偏好宽度。最近作品长标题在左右边缘渐隐，首次短暂停顿后从右向左单向循环，下一份标题从右边接续进入，不向右倒滑；短标题静止，收起或无溢出时停止计时。其他标题、路径与文件名不撑大窗口，完整内容放在提示或详情里。

视频库提供卡片悬停删除图标、所选作品删除按钮、Delete 键及右键菜单；播放器可删除当前视频，图文查看器可删除整个作品或单个选中媒体。删除均先确认，取消不影响播放或文件。删除前释放软件内播放器占用，等待库扫描和缩略图作业结束，完成后更新库、首页、侧栏与图文清单；最后一项删除后移除空图文目录。删除记录仍只隐藏记录并保留文件。

首次安装选择下载目录；软件设置与库底部均可更改。更改时停止接收新下载，后台复制并逐个 SHA-256 校验，原子写入设置并更新原记录路径，再删除校验一致的原文件和本次迁移涉及的空目录。视频、图文、配乐、回执与下载临时文件一起迁移；同名目标不覆盖，无法找到的旧作品记录继续保留。复制阶段可取消；重启后根据持久化迁移记录恢复。被占用的原文件留待继续清理，其他个人文件与未参与迁移的目录保留。

设置默认 820×680，最小 700×560，保留原生窗口缩放和右下角拖动手柄；内容可滚动，底部操作固定可见，下载位置位于第一项。设置、播放器、图文查看器、更新和日志统一蓝灰控件。图文文件显示“图片 01”等可读名称，原文件名保留在提示。软件内播放器保留暂停、进度、音量、全屏和默认播放器恢复入口。

下拉框通过点击展开或键盘选择。鼠标滚轮不改变选项，即使控件已有焦点；滚轮继续用于滚动所在页面，防止无意更改格式、音质、登录来源或排序。

更新页保留真实版本、官方说明、字节进度、校验和独立安装助手。更新检查和下载安装行为不随视觉修改改变；安装仍要求确认。紧凑窗口可滚动查看内容。

播放器与图文查看器为独立普通窗口，不设置原生 owner 或 Qt transient parent；使用最小化、最大化、关闭按钮，可把视频库切换到它们前面。主软件退出、迁移或删除对应媒体时，仍显式关闭并释放解码器；沿用软件图标与黑白样式。

## 图标与验收

app.svg 为用户确认发布的原创折帧标志：两片对称的圆角折面沿对角线错开，保留中间留白，统一使用黑色线条。界面不使用黑底方块；原生图标导出添加白色底板以兼顾深色任务栏。操作 SVG 使用同一线条规范；packaging/render_icon.py 从 SVG 生成 app.png 与包含 16 / 24 / 32 / 48 / 64 / 128 / 256px 的 Windows ICO。不要用换色旧图标或其他产品品牌标志代替重新设计。

使用既有 Qt 流程做真实截图与事件检查，覆盖 100%、150%、200% 缩放、默认/紧凑/宽窗口、侧栏收起展开、独立搜索、设置缩放、粘贴与提交、错误、空状态和内置播放。当前结果与运行方式见 UI_REVIEW.md。未经大人确认，不打包发布或上线；历史 v2 交付报告不代表本轮安装包已重新验收。

更新弹窗默认 760×600、最小 560×420，并按屏幕工作区限制初始大小，支持拖动缩放。发布说明共用正文排版，限制 Markdown 标题字号；更新页说明随内容增高，只用外层滚动，卡片右侧与滚动条留 20px 间隔，底部操作固定单行。剩余时间以 10 秒采样窗口与时间加权平滑估算，每秒更新；初始显示估算中，5 秒无数据显示等待网络，重试重置估算。

更新页当前版本与最新版本共用 display 字号和字重，并保持相同基线。底部开源项目与历史版本使用 16px 文本入口，固定靠右，与卡片右边界对齐；滚动条出现或消失时同步调整，不使用两侧重复弹性留白。

2026-10-22：大人暂停 2.1.3 发布并确认蓝灰色重设计。沿用轻量布局、黑白原创 Logo 和简洁文案，颜色统一由 ui_theme.py 管理。新主题需先检查本地预览，再授权发布。
