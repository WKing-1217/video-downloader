# Windows 黑白 UI 约定

本轮仅修改 Windows 原生 Qt / PySide6 桌面端，用户已确认界面并授权发布 Windows 2.1.0。遵守根目录 AGENTS.md 中大人明确确认的 UI 偏好。下载、账号、视频库、播放和更新服务继续使用既有实现，Android 保持 1.0.4。

## 首页与导航

默认 1120×780，最小 860×620。背景近白，文字与交互使用黑白灰，媒体内容保留原色。颜色、字号、间距和组件尺寸统一定义在 ui_theme.py。

首页内容居中，最大宽度 780px：一句问候、一个链接输入框、右侧独立粘贴图标和黑色箭头按钮，下方并排展示最近三个真实作品缩略图。标题只作为作品内容显示，时长位于封面角落；不增加平台徽章、日期、体积、快捷键教程、目录栏、口号或说明副标题。没有任务时隐藏整个任务区域，没有作品时不生成虚假缩略图。

左侧默认 72px 窄图标栏，以细竖线分隔内容区。顶部为原创折帧线条 Logo，下方只保留下载、视频库和更新三个入口，移除收起状态的独立搜索图标，底部为灰阶账号 / 设置入口。默认不展示文字标签，通过悬停提示与无障碍名称识别。点击 Logo 后，整个全高侧栏展开到 280px，显示导航名称、真实最近作品以及底部设置入口；顶部提供搜索和收起按钮。展开是主窗口布局的一部分，不弹小菜单。两个状态共享当前页面和导航选中状态。

搜索入口打开独立的 640×480 窗口浮层，过滤真实作品标题并直接打开作品，支持方向键选择、Enter 打开、Escape 关闭。搜索不切换底层页面，不修改视频库筛选条件，也不占据一个页面选中状态。Ctrl+K 打开搜索，Ctrl+B 切换侧栏。

## 输入与真实状态

粘贴按钮、Ctrl+V 和右键粘贴仅填入内容。点击黑色箭头或按 Enter 后验证并排队，同一规范化链接去重。不监听全局剪贴板，不在输入未完成时下载。

有实际任务时才在输入框下方显示标题、状态、进度与必要操作。解析、下载和合并在独立后台进程执行；实际字节、速度和剩余时间来自原服务，未知总量不生成假百分比。失败、取消、完成以文字和图形区分，使用灰阶。失败或取消后不显示继续下载的速度与 ETA，保留重试与登录入口。

## 作品与弹窗

首页三个预览共用视频库后台缩略图生成与缓存，鼠标单击和键盘回车均可打开作品。库使用原有 QListView 模型和绘制委托，默认三列、最小窗口两列，更宽窗口适应可用宽度。空库与搜索无结果使用简短状态和恢复按钮。

长标题、路径与文件名不撑大窗口，完整内容放在提示或详情里。删除记录保留本地文件，删除本地文件继续确认。旧目录仍纳入扫描，修改位置不移动旧作品。

设置默认 820×680，最小 700×560，保留原生窗口缩放和右下角拖动手柄；控件布局随宽度伸展。设置、播放器、图文查看器、更新和日志统一灰阶控件。图文文件显示“图片 01”等可读名称，原文件名保留在提示。软件内播放器保留暂停、进度、音量、全屏和默认播放器恢复入口。

更新页保留真实版本、官方说明、字节进度、校验和独立安装助手。更新检查和下载安装行为不随视觉修改改变；安装仍要求确认。紧凑窗口可滚动查看内容。

## 图标与验收

app.svg 为用户确认发布的原创折帧标志：两片对称的圆角折面沿对角线错开，保留中间留白，统一使用黑色线条。界面不使用黑底方块；原生图标导出添加白色底板以兼顾深色任务栏。操作 SVG 使用同一线条规范；packaging/render_icon.py 从 SVG 生成 app.png 与包含 16 / 24 / 32 / 48 / 64 / 128 / 256px 的 Windows ICO。不要用换色旧图标或其他产品品牌标志代替重新设计。

使用既有 Qt 流程做真实截图与事件检查，覆盖 100%、150%、200% 缩放、默认/紧凑/宽窗口、侧栏收起展开、独立搜索、设置缩放、粘贴与提交、错误、空状态和内置播放。当前结果与运行方式见 UI_REVIEW.md。未经大人确认，不打包发布或上线；历史 v2 交付报告不代表本轮安装包已重新验收。
