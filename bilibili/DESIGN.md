# Windows v2 产品与界面约定

原生 Qt Widgets 桌面工具，核心对象为链接、真实任务、本地媒体和软件版本。保留既有下载、最高可用音画选择、登录和图文能力。Windows v2 与 Android v1.0.4 分别发布版本。

固定窄侧栏，严格三个主页面：下载、我的视频、软件更新。默认 1050×720，最小 860×620，适应系统 DPI。颜色、字号、圆角和间距集中在 ui_theme.py：浅灰背景、白色面板、深色正文、玫红色选择与主操作，使用 Segoe UI / 微软雅黑。卡片随视口排列，不叠加网页框架或装饰性仪表盘。

首页以主动粘贴为入口。Ctrl+V、右键粘贴和粘贴按钮验证后自动排队；手动输入未完成时不启动，不监听全局剪贴板。同一规范化链接去重。解析、下载和合并在独立后台进程，界面显示实际字节、速度、状态及可用取消/重试；日志在次级窗口。

我的视频采用 QListView 模型与绘制委托，按可见行请求缩略图，后台并发有界，内存图片缓存有上限。真实缩略图、标题、时长、大小与完成时间明确分层。底部固定目录区。旧目录自动导入，移动与缺失按真实文件状态同步；移除记录与删除文件不同，物理删除必须确认。

点击卡片在 Qt 内置播放器打开。保留播放/暂停、进度、音量、全屏与时间。捆绑 Qt FFmpeg 解码组件并显式加载，避免系统缺少 AV1 / HEVC 解码扩展；渲染使用 QVideoSink 与原生绘制，解码错误显示原因并提供默认播放器。图文、实况和配乐在次级作品查看器中预览。

第三页集中版本、真实 GitHub Release Notes 和更新进度。后台检查无新版不提醒，错误只落在更新页；发现新版的小提示只负责暂缓或进入第三页。未知总长不造百分比。下载安装使用真实回调、校验和独立助手，确认后才退出；助手就绪后旧程序才关闭，新版启动确认后才视为成功，失败恢复旧版。

设置、浏览器来源、账号扫描、网页登录和诊断日志位于右上角次级菜单/窗口，不增加第四主页面。登录来源收起时不响应滚轮；图标采用同一 SVG 系统。普通界面不展示开发提示、虚假进度或内部协议名。

主要风险及验证：主动粘贴去重、未完成成品隔离、缩略图阻塞、解码缺失、旧目录丢失、更新零进度、安装失败和旧库遮蔽。对应自动/受控 HTTP 测试、真实 Qt 键盘事件、真实媒体解码、冻结程序联网验收、原 v1.0.4 副本覆盖安装及恢复检查。细节见 V2_DELIVERY.md。
