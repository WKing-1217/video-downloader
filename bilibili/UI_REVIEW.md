# Windows 2.1.0 · 界面与发布验收

Windows 2.1.1 的目录迁移、可调侧栏、单向滚动、独立播放器及删除功能见 [本轮检查记录](STORAGE_REVIEW.md)。下文为上一轮 2.1.0 发布记录；同名截图目录已由当前源码重新渲染。现在“预览新版UI.bat”打开 `build/storage-preview` 下的本轮独立预览。

本轮按照用户提供的首页截图重新设计，用户已于 2026-10-22 确认并授权发布。Windows 版本为 2.1.0，Android 保持 1.0.4。

## 查看

双击同目录的“预览新版UI.bat”，或运行：

    & '.\bilibili\.venv\Scripts\pythonw.exe' bilibili/preview_ui.py

这是实际 Qt 界面。首页仅保留问候、链接输入框、粘贴图标、黑色箭头及三张作品预览；左侧窄图标栏提供下载、视频库、更新和底部设置入口，已移除收起状态的搜索图标。点击顶部 Logo 展开整条全高侧栏，显示导航和真实最近作品，顶部按钮可收起。搜索从展开后的顶部入口或 Ctrl+K 独立弹出，关闭后保留原页面与视频库筛选，支持方向键和 Enter；设置默认放大到 820×680 并可拖动调整。粘贴只填入，黑色箭头或回车开始下载。用户的界面偏好已写入根目录 AGENTS.md。

预览的设置和库位于 build/ui-preview/preferences，示例作品是已有文件的独立副本。后续下载也写入预览目录，启动时不会自动扫描正式浏览器登录或检查更新；主动点击登录、扫描与更新功能时，执行对应的真实操作。交互预览不注入虚假下载或更新状态。
